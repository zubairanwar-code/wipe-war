# Fluorescent Germ Analysis Improvements Walkthrough 🦠🚀

We have implemented a suite of features to transition the **Fluorescent Germ Analysis Tool** from a simple interactive script into a robust, automated computer-vision tool.

---

## 🛠️ Summary of Key Enhancements

Here is a summary of the improvements now available in the codebase:

1.  **Unified Computer Vision Logic**: Refactored [main.py](file:///Users/zubairanwar/code/wipe-war/main.py) to wraps [code.py](file:///Users/zubairanwar/code/wipe-war/code.py)'s implementation. This eliminates the duplicate grayscale logic in favor of the scientifically superior **Blue Channel Extraction** methodology.
2.  **Flexible File Naming & Auto-Pairing**: Extended regex matching to support files without the `run{N}_` prefix, automatically matching pairs (e.g. `clorox_before.jpg` and `clorox_after.jpg`) and inferring the run number from parent directory names (like `run1/`).
3.  **Automated Calculations**: The program now automatically calculates the **Percent Removed** metric, handling edge cases like negative values (spreading of germs) and division by zero.
4.  **Matplotlib Charts**: Integrated matplotlib to automatically generate professional bar charts comparing the cleaning efficiency of different wipes.
5.  **Multi-Format Reporting**: Added automatic generation of CSV (`results_summary.csv`) and Markdown (`results_summary.md`) reports.
6.  **Dual Execution Modes (argparse)**: Added support for command line arguments (e.g. `python code.py -d photos_test -t 150`) to enable automation, while preserving the friendly interactive CLI prompts.
7.  **Visual Tuning GUI ([tune_threshold.py](file:///Users/zubairanwar/code/wipe-war/tune_threshold.py))**: Created an interactive GUI tool with OpenCV sliders to let you fine-tune the brightness threshold and crop area in real-time.
